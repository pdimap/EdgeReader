# EdgeReader 2.0.2 — чтение скопированного текста

1. Установите `EdgeReader-2.0.2-Setup.exe` и запустите программу.
2. Выделите нужный текст в Chrome, Word, PDF или другом приложении.
3. Нажмите **Ctrl+C** и дождитесь копирования.
4. Нажмите **Ctrl+Alt+X** — программа прочитает текст из буфера.

Ctrl+Alt+P — пауза/продолжение, Ctrl+Alt+Z — остановка.
Кнопка «Проверить звук» произносит встроенную фразу; «Проверить текст в буфере» показывает количество символов без передачи в TTS.

Программа больше не извлекает выделение автоматически и не нажимает Ctrl+C за пользователя. Она только читает Unicode-текст из буфера, не меняя HTML, изображения или другие форматы. Если копирование не произошло, в буфере может остаться предыдущий текст: перед озвучкой нового фрагмента обязательно нажмите Ctrl+C. Изображения и сканы без OCR не читаются.

Озвучиваемый текст отправляется в онлайн-сервис Microsoft; нужен интернет. Установщик неподписанный, контрольная сумма поставляется рядом. Python на компьютере пользователя не нужен.

## Сборка
Windows x64, Python 3.11, зависимости requirements.txt и PyInstaller 6; упаковка через workflow `.github/workflows/windows-build.yml`, установщик Inno Setup 6.

## Проверки
`python -m unittest discover -s tests -v`
Windows CI проверяет настоящий Clipboard с Unicode и HTML, неизменность форматов и путь зарегистрированный обработчик горячей клавиши → буфер → вызов озвучивания. Регистрация клавиш и аудиовывод в этом тесте заменены наблюдателями. Физическая глобальная клавиша в CI не подтверждена: попытка синтетического ввода не вызвала обработчик. Есть отдельная кнопка «Прочитать буфер». Также выполняются упаковка, установка, запуск и удаление.
Слышимый звук на пользовательском компьютере не подтверждается CI. Пользователь подтвердил работу кнопки проверки звука в предыдущей версии.
